# Изображения

`app/assets/images/roma-crest.png` — эмблема AS Roma с надписью ROMA / 1927, выбранная владельцем для шапки сайта. PNG хранится в проекте; при открытии сайта запросов к стороннему источнику изображения нет.

Копия получена 03.11.2026 из [football-logos](https://github.com/luukhopman/football-logos/blob/master/logos/Italy%20-%20Serie%20A/AS%20Roma.png), без изменения изображения. Права на эмблему принадлежат соответствующему правообладателю.
