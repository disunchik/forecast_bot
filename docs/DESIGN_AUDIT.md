## Область и методика

Rails 8.1.3.1 / Ruby 4.0.6, Windows Chrome 156. Использованы отдельные временные базы `visual.sqlite3`, `regression.sqlite3` и `system.sqlite3` в `/tmp/roma-hallmark-audit`; рабочие данные не использовались. Все аккаунты и содержимое снимков вымышлены.

Hallmark `sloplint --genre modern-minimal --scope app --render --before`, затем `--kept`: главная, профиль, форма прогноза и административный список матчей. Измерения на ширинах 320, 375, 414, 768, 1024, 1280, 1440 и 1920 px. На каждом этапе сделано 20 снимков; финальное сравнение содержит одинаковые исходные и обновлённые состояния.

В итоговом проходе: **0 FAIL, 0 открытых REFLEX, 0 WARN**. Сохранены **27/27 ссылок, 13/13 полей, 15/15 заголовков, 7/7 учитываемых элементов figures**. Это инвентаризация четырёх страниц, а не доказательство покрытия всего приложения.

Отдельный временный браузерный сценарий выполнил **96 успешных проверок** на десяти страницах: главная, профиль, настройки, ачивки, прогноз, обзор админки, матчи, правила, вход и регистрация. Ширины 320/390/768/1440 px; проверены отсутствие горизонтального переполнения страницы, загрузка эмблемы, меню из 12 пунктов в две строки на ПК, текущая навигация, выделение выбранного варианта, отступы формы и видимость всей истории ЗБ на телефоне. Сценарий не добавлен в постоянный набор.

Полные снимки до/после просмотрены вручную. Финальный обзор выполнен в этом чате (`in-thread`); найденный при обзоре слипшийся фильтр сезона исправлен. Дополнительно снята главная с сохранённым прогнозом.

## Проверки приложения и ограничения

- `bin/rails db:test:prepare test`: **131 тест / 781 проверка**, 0 ошибок, 0 пропусков, два процесса, seed 50201; отдельная временная тестовая БД.
- `bin/rubocop`: **114 файлов**, нарушений нет.
- `bin/rails zeitwerk:check`: успешно; штатное предупреждение о `test/mailers/previews`.
- `git diff --check`: успешно.
- `bin/rails test:system` через Windows ChromeDriver: **5 тестов / 39 проверок, 1 ошибка**, остальные четыре сценария проходят. Мобильный сценарий не находит доступный переключатель «Голов не будет» после заполнения нулевого счёта. На чистой временной копии **исходного `34f7548`** тот же сценарий воспроизвёл **ту же ошибку на той же строке 25**, seed 36790. В контрольной копии изменён только порт тестового сервера 3101 → 3102; тестовые действия и проверки сохранены. Причина мобильного сбоя в этой связке Windows/WSL/ChromeDriver не установлена; полный system-набор не объявляется зелёным. Тесты не ослаблялись.
- Первичный визуальный проход также сообщал ошибки service worker из-за потерянного `Accept` во временном прокси аудита. Прокси исправлен, ошибки исчезли без изменения приложения. Поэтому исходные 51 FAIL нельзя целиком считать дефектами приложения или сравнивать с итогом как число уникальных багов.
- Статический анализ Hallmark не читает ERB напрямую: проверены общий CSS, реально отрисованные страницы и их инвентарь. Прочие ERB-шаблоны не считаются полностью проверенными этим линтером.
- Оставлены с объяснением: фирменная золотая полоса, единое оформление полей и горизонтальная прокрутка широких административных таблиц. Отдельная перестройка всех административных таблиц в мобильные списки выходит за текущую полировку.
- Результаты локальных проверок не заменяют GitHub Actions. Во время работы GitHub был недоступен из WSL; обращение через подключённый GitHub также завершилось ошибкой соединения. Новый CI не подтверждён.
