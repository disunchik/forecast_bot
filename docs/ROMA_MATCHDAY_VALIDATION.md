По скриншоту владельца устранено слияние внешнего фона с рабочим полем. Новый `heritage-ground` (#e6e0d5) темнее `paper`; фото затухает на последних 20% вместо диапазона 55–95%. Размеры слоя, кадрирование и opacity .24 сохранены.

- Осмотрены 6 актуальных снимков: главная и профиль на 1440/390px, отдельно короткая главная без открытых матчей. Пустое состояние получено на отдельной копии временной тестовой SQLite; рабочие данные не менялись.
- Повторно пройдены **35 защитных браузерных проверок**, включая непрозрачность рабочего поля, доступность действия, клавиатуру, увеличение текста 200%, отсутствие фото, forced colors и reduced transparency.
- Независимый визуальный ревьюер подтвердил различимость фото под футером и сохранность мобильного интерфейса; материальных замечаний нет.
- Hallmark с реальным рендером пустой главной: **0 FAIL / 0 WARN / 8 ANSWERED**. `git diff --check`: успешно.
- Правка затрагивает CSS и дизайн-контракт. Rails/RuboCop/Zeitwerk повторно не запускались: Ruby/ERB не менялись; прежние результаты ниже относятся к предыдущему проходу.

## Визуальная проверка

Hallmark: 20 исходных и 20 финальных снимков четырёх контрольных страниц; дополнительные desktop/phone-снимки таблицы, туров, админского обзора, авторизации и текстового вопроса. Проверялись реальные Rails-ответы, а не статические подмены.

Финальный Hallmark: **0 FAIL, 0 открытых REFLEX, 1 WAIVED, 8 ANSWERED, 1 WARN**. Сохранены **28/28 ссылок, 13/13 полей, 15/15 заголовков** четырёх контрольных страниц. Это ограниченная инвентаризация, а не доказательство покрытия всего приложения.

- Поля счёта намеренно крупнее рекомендации линтера: `min-height:72px`, фактически 74px с текущим шрифтом/межстрочным интервалом. Обоснование — читаемость четырёх независимо вводимых чисел и удобство на телефоне; обычные контролы сохраняют 44–52px.
- Единственный `WARN kept`: числовой инвентарь учитывает 6/7 исходных значений и сообщает `10:50`. Между сравнениями визуальная база дополнена закрытым туром, текстовым вопросом и операциями. Вывод времени через `moscow_time(match.kickoff_at)` сохранён; это предупреждение не скрыто и не объявлено исправленным багом приложения.
- Независимый reviewer нашёл тесные метрики админки и перекрытие сравнительных данных тура на телефоне. Исправлены: сезон отдельной строкой, два счётчика рядом; короткий `#`, свободная область HT/FT и видимая подсказка прокрутки. Повторный verdict: **оба замечания resolved, disposition ship**. Этот вердикт относится к двум исправлениям, а не к полной сертификации приложения.

Снимки, HTML-сравнение Hallmark, JSON измерений и временные браузерные сценарии находятся вне репозитория в каталоге артефактов чата `hallmark-audit/roma-matchday`. Новых производственных растровых ресурсов нет; эмблема использует существующий локальный файл.

## Ограничения

`bin/rails test:system` через Windows ChromeDriver: **5 тестов, 41 проверка, 0 failures, 1 error**. Четыре сценария прошли, включая административный ввод голов, предварительный расчёт и подтверждение. Мобильный сценарий останавливается на строке 39: `Unable to find visible radio button "Голов не будет" that is not disabled`. Ранее этот тип сбоя воспроизводился до редизайна; причина в этом задании не устранена. Набор не объявляется зелёным, тесты не ослаблялись. Отдельный браузерный сценарий с нулевым счётом прошёл, но не заменяет этот system-тест.

Эмулированные viewport и клавиатурная проверка Chrome не заменяют физический телефон, VoiceOver/NVDA, полную проверку увеличения текста и пользовательское исследование новичков. WCAG 2.2 AA — цель проверки, не заявление о полной сертификации. Новый GitHub Actions/деплой в рамках этой реализации не запускался.
