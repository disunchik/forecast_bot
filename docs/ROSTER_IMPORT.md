# Импорт состава AS Roma

Источник: https://www.asroma.com/en/men/players-and-staff — официальная HTML-страница мужской команды. Подключение футбольных API, ключи и платные сервисы не используются. В приложение попадают только имена и ключи профилей; изображения, позиции, номера и тренерский штаб не импортируются.

## Проверенная копия

Файл config/data/roma_roster.json содержит 25 футболистов, русские имена и варианты написания. Дата проверки: 2026-11-12T10:14:01Z. Исходный HTML получен через Windows; прямое HTTPS-соединение из текущего WSL заканчивается тайм-аутом. Поэтому свежая загрузка может быть недоступна в этой среде, а сохранённая копия выбирается явно и подписана своей датой.

SHA-256 проверенного исходного HTML: `1075c8c7feb7381b818ffa49b4c041e5d4f94a5b1d7c761217eb75d37af255ce`.

Fixture test/fixtures/files/roma_roster.html сохраняет наблюдаемую структуру карточек и факты имён/профилей, без медиа и скриптов; номера в ней — технические значения, они не используются импортом. Парсер отдельно проверен на полном исходном HTML: 25 профилей, штаб исключён. Чтобы обновить копию, заново получите и проверьте официальный состав, сохраните исходные profile-key/original-name и исправленные русские имена/варианты, обновите verified_at и источник проверки. Не выдавайте старую копию за свежую.

## Поведение

- GET /admin/players/import — выбор свежего источника или копии; POST /admin/players/import/preview — предпросмотр, без записи футболистов; POST /admin/players/import — применение.
- Доступ только админам. Подписанный предпросмотр действует 30 минут и привязан к администратору и состоянию каталога. Источник повторно не запрашивается при сохранении.
- Ключ профиля приоритетнее написания. Имена нормализуются по Unicode, регистру и пробелам; используются подготовленные варианты кириллицы/латиницы. Неоднозначное сопоставление выбирает админ; нельзя привязать один ID к двум профилям.
- Уже связанные/распознанные записи сохраняют имена, ID и active. Неизвестное русское имя по умолчанию пропущено. Создание дубля по нормализованному имени блокирует всю операцию.
- SQLite write lock и повторная проверка состояния защищают конкурентные сохранения. Уникальный индекс дополнительно защищает ключ профиля. Подпись, состояние, валидации и аудит проверяются сервером; ошибка откатывает весь пакет.
- Источник фиксирован. Разрешены не более двух HTTPS-перенаправлений внутри asroma.com/www.asroma.com; open timeout 4s, read timeout 8s, общий лимит 20s и 2 MiB ответа. Пустой, неполный или повреждённый ответ — ошибка, без тихого переключения на копию.
- До рабочей записи выполняется существующий bin/backup вне транзакции; затем состояние проверяется заново под lock. Копии вне Git, права файлов и integrity_check проверяются скриптом. FORECAST_BACKUP_DIR позволяет выбрать закрытый каталог вне проекта. В Rails test автоматическое копирование отключено; реальные записи для тестов не используются.

История импорта доступна в Audit log: player.create, player.roster_link и итоговый players.roster_import с источником, датой и числом изменений.
